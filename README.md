A tiny Node 22 program for the make.fun bounty
[One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee).

`main.ts` writes one pickup line to `/output/entry.txt`, spoken by the
vending machine itself: the coil in slot B4 is holding the passing human's
favorite snack hostage and offers to drop it free — exact change not
required, just one smile. The machine's own world (coil, slot, button,
drop, exact change) carries the joke, and the punch lands in the last few
words. No network, no randomness, no input — the same line on every run.

Run it with Node 22:

```sh
node main.ts
```
